IMAGE AND VIDEO FOURIER TRANSFORM PROJECT

Included:
- image_video_fourier_transform.py: Google Colab Python code.
- sample_images/sample_colour_image.png: example colour input.
- sample_images/sample_image_grayscale.png: grayscale result.
- sample_images/sample_image_fourier_spectrum.png: Fourier spectrum result.
- sample_images/sample_video_frame.png: example video frame.
- sample_images/sample_video_frame_grayscale.png: grayscale video-frame result.
- sample_images/sample_video_frame_fourier_spectrum.png: video-frame Fourier spectrum.

To run:
1. Open Google Colab at https://colab.research.google.com/
2. Create a notebook and paste in the Python code.
3. Run the code and upload your own image when prompted.
4. Upload your own video when prompted.

The included video-frame picture is a still demonstration image, not a complete video.
